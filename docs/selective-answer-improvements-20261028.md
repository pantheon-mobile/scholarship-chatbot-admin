# 精度改善検証からの個別反映

## 採用する変更

Web取り込み時にHTMLの定義リスト（dl / dt / dd）を保持する。
従来は定義名と、段落タグに囲まれていない説明が欠落し、条件や例外が
何に適用されるか分からなくなる場合があった。定義名と説明を原文順に
出力し、内部の段落・箇条書きを重複して出力しないようにした。

検証候補で確認した資料変換の欠落対策だけを既存処理へ移植する。
モデルによる回答の反復点検・修正や、実験用の新しい回答経路は導入しない。
回答時のモデル呼び出し回数や検索設定は変更しない。

## 確認結果と適用範囲

- 定義名、条件、例外、入れ子の説明が順序を保って一度ずつ残る自動試験を追加。
- バックエンド試験642件成功、6件スキップ（明示実行が必要なBedrock実推論）。
- 追加の有料回答比較は実施していない。この変更だけによる回答正解率の向上は未測定。
- 次回以降のWeb取り込みに適用される。登録済みの変換文書と検索索引は
  デプロイだけでは変更されず、対象Webデータソースの再取り込みが必要。

## 今回反映しない候補

原文を使った検索断片の補完、段落ごとの追加検索、回答の検査・修正の
組み合わせには、対象制度・例外条件の混同と応答時間・費用の課題が残る。
これらを、全体の検証結果から独立した効果が証明された変更とは扱わない。
候補の成功例を既存方式へそのまま適用できるとの保証もしない。
