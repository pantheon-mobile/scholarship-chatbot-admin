# Excelダウンロードの書式方針

2026-09-16時点のユーザー決定。今後の仕様変更時には以下の決定と実装を合わせて更新する。
参照資料: 奨学金ファイルダウンロードフォームExcel_20260916.xlsx

1. 定義表とサンプルの相違は「フォーム定義」を優先する。
2. フォントはすべて游ゴシック11ptに統一する。
3. カテゴリ一覧は登録データの最大階層数に応じた可変列。データなしの場合は従来どおりID・カテゴリ1。
4. 列幅は定義表E列「幅」を使用し、F列のピクセル換算は使用しない。
5. 4階層以上もカテゴリ4・カテゴリ5のように別列で出力する。カテゴリ3への連結は行わない。すべてのカテゴリ列は幅49.3、折り返しあり。既存の名称に含まれる `/` はそのまま保持する。

共通書式と各出力の列幅・折り返し・配置は `backend/app/services/excel_format.py`、カテゴリ階層の出力は `backend/app/services/category_service.py` に集約している。
ヘッダーは背景F8F7F7、黒文字、縦横中央、枠線なし。データは黒文字、上寄せ、枠線なし。列ごとの配置・折り返しは定義表に従う。
種別・FAQ区分のヘッダーは現在設定されている表示ラベルを継続使用する。

## 追加確認への回答
- 標準行高はサンプルに合わせて18pt。データ行は明示改行・列幅・全角半角の文字幅に応じて高さを調整する。
- Excelの行高上限409.5ptまで拡張する。文字の削除や短縮は行わない。実際の折り返し位置はExcelのフォント描画に依存するため、行数計算は推定。
- FAQ登録フォーマットのヘッダー固定はサンプルどおり解除。URL入力用・チャット履歴・ユーザリストの既存固定は維持する。

- チャット履歴・ユーザリストの日時は `YYYY/MM/DD HH:mm:ss`（日本時間）とする。秒表示は維持。アクセスログ・操作ログのCSV日時は従来形式を維持。
