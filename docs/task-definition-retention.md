# ECSタスク定義の保持

Frontend・Backend・Workerのタスク定義は、DeletionPolicyとUpdateReplacePolicyをRetainに設定する。
更新で新しいリビジョンを登録してサービスを切り替え、古いリビジョンは登録解除せず保持する。スタックから定義を除去するときも保持する。

タスク定義は起動設定であり、保持するだけでコンテナを起動するものではない。稼働サービス・定期処理はCDKが指定する新しい定義を使用する。DB・S3・サービスの削除方針はこの設定では変更しない。

旧定義は蓄積し、CloudFormationの管理対象から外れる。必要に応じて管理者が利用状況を確認して整理する。機密値はSecrets Manager参照とし、旧定義に平文の秘密値を記載しない。

この保持方針により、通常の更新・削除でecs:DeregisterTaskDefinitionを呼ばず、同操作のアカウント全体への許可追加を不要とする。既に発生した古い定義のDELETE_FAILEDイベントは過去の記録として残る。

2026年9月29日の先行更新は古い3定義の登録解除に失敗したが、最終状態UPDATE_COMPLETE、自動デプロイ成功。今回の保持設定は以降の更新で同じ警告と再試行待ちが生じないようにするもの。
